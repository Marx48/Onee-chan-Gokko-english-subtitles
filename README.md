# Onee chan Gokko(Playing sister) english subtitles
Unofficial english subtitles for episode 2 and 3(when released) for Onee-chan Gokko. Edited and refined in Aegisub.
This project contains an edited and refined .ass subtitle file for the second episode of the anime. The subtitles were revised using Aegisub, with attention to timing, readability, line breaks, and overall presentation.

About This Project
The goal of this project is to provide a revised subtitle file for viewers who want to watch Episode 2 with English subtitles.
The subtitle file was extracted from an existing source and subsequently edited and refined. This project is an independent subtitle-editing effort and is not an official release.

Contents
Episode 2.ass. Edited English subtitles in Advanced SubStation Alpha (.ass) format.

Editing
The subtitle file was edited using Aegisub, a subtitle editor that supports advanced formatting, positioning, styling, and timing adjustments.

How to Use
Obtain the corresponding video from its official source.
Download the .ass subtitle file from this repository.
Open the video in a compatible media player.

Load the subtitle file, or place it alongside the video with a matching filename if your player supports automatic subtitle loading.

Subtitle timing may need adjustments if your video source uses a different cut or version.
